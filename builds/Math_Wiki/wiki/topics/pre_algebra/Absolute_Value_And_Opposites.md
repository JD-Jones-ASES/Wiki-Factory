# Absolute Value and Opposites

## Definitions

- **Opposite** --- Two numbers are opposites if they are the same distance from zero but on opposite sides of the number line. The opposite of~a is written~-a. itemize[nosep] The opposite of 7 is -7. The opposite of -4 ...
- **Absolute Value** --- The absolute value of a number is its distance from zero on the number line. We write the absolute value of~a as~a. itemize[nosep] -5 = 5 3 = 3 0 = 0 itemize
