# Scale Drawings and Maps

## Definitions

- **Scale** --- A scale is a ratio that compares a length in a drawing or model to the corresponding actual length. \[ scale = drawing length/actual length \] A typical map scale might read ``1 cm : 50 km,'' meaning ...
- **Scale Factor** --- The scale factor is the ratio of any length in the scale drawing to the corresponding actual length, expressed as a single number. If the scale is 1 : 200, the scale factor is 1{200}.
- **Scale Drawing** --- A scale drawing is a drawing that uses a scale to represent an object as larger or smaller than the actual object. Common examples include maps, blueprints, and model plans.
