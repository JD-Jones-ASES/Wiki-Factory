## Definitions

- **Zero Property of Multiplication** --- The product of any number and~0 is~0. \[ a 0 = 0 \]

## Key Properties

- **Commutative Property of Addition** --- Changing the order of the addends does not change the sum. \[ a + b = b + a \]
- **Commutative Property of Multiplication** --- Changing the order of the factors does not change the product. \[ a b = b a \]
- **Associative Property of Addition** --- Changing the grouping of the addends does not change the sum. \[ (a + b) + c = a + (b + c) \]
- **Associative Property of Multiplication** --- Changing the grouping of the factors does not change the product. \[ (a b) c = a (b c) \]
- **Identity Property of Addition** --- The sum of any number and 0 is that number. Zero is the additive identity. \[ a + 0 = a \]
