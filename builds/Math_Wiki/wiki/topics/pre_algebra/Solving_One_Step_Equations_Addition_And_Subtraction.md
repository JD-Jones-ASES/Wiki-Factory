## Definitions

- **Equation** --- An equation is a mathematical sentence that uses an equal sign (=) to show that two expressions have the same value. Example: x + 5 = 12.
- **Solution of an Equation** --- A solution of an equation is a value of the variable that makes the equation true. For x + 5 = 12, the solution is x = 7 because 7 + 5 = 12.
- **Inverse Operations** --- Inverse operations are operations that ``undo'' each other. Addition and subtraction are inverse operations. Multiplication and division are inverse operations.

## Key Properties

- **Addition Property of Equality** --- If a = b, then a + c = b + c. You can add the same number to both sides of an equation.
- **Subtraction Property of Equality** --- If a = b, then a - c = b - c. You can subtract the same number from both sides of an equation.
