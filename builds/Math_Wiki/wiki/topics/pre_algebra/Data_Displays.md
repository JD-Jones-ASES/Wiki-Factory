## Definitions

- **Bar Graph** --- A bar graph uses horizontal or vertical bars to compare amounts across categories. The length (or height) of each bar shows the value for that category.
- **Circle Graph (Pie Chart)** --- A circle graph (also called a pie chart) is a circle divided into sections (slices). Each section represents a part of the whole. All the sections together equal 100\% of the data.
- **Line Graph** --- A line graph uses points connected by line segments to show how data changes over time. The horizontal axis usually shows time, and the vertical axis shows the measured quantity.
- **Dot Plot** --- A dot plot uses a number line with dots stacked above each value to show how often that value occurs in a data set.
