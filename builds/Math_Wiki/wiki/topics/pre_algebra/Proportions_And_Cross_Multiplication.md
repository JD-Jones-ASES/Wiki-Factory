## Definitions

- **Proportion** --- A proportion is an equation that states two ratios are equal. \[ a/b = c/d, b 0,\; d 0 \] We read this as ``a is to b as c is to d.''

## Key Properties

- **Cross Products Property** --- If a{b} = c{d} (with b 0 and d 0), then the cross products are equal: \[ a d = b c \] This property works in both directions: if a d = b c, then a{b} = c{d}.
