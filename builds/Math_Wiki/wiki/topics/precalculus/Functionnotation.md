## Definitions

- **Function Notation** --- If f is a function with input x, we write f(x) (read ``f of x'') for the output. The expression f(x) does not mean ``f times x.''

## Key Properties

- **Common Domain Restrictions** --- itemize[nosep] Division by zero: if f(x) = 1{x}, then x 0. Square root of a negative: if f(x) = x, then x 0. itemize
