## Definitions

- **Relation** --- A relation is any set of ordered pairs. The relation may be described by a list of ordered pairs, a table, a graph, or an equation.
- **Domain and Range** --- The domain of a relation is the set of all first coordinates (x-values). The range is the set of all second coordinates (y-values).
- **Function** --- A function is a relation in which every element of the domain is paired with exactly one element of the range. In other words, no x-value is repeated with a different y-value.
- **Relation** --- A relation is any set of ordered pairs (x, y). The set of all x-values is the domain, and the set of all y-values is the range.
- **Function** --- A function is a relation in which every input (x-value) is paired with exactly one output (y-value). In other words, no x-value appears more than once with a different y-value.

## Key Properties

- **Vertical Line Test** --- A graph in the coordinate plane represents a function if and only if every vertical line intersects the graph in at most one point.
- **Vertical Line Test** --- A graph represents a function if and only if no vertical line intersects the graph at more than one point.
