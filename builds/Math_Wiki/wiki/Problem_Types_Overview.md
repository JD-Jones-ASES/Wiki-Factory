# Problem Types Overview

> [[_overview|Home]] > Problem Types

Every category of practice problem this wiki can generate. Each problem type is tied to a Python generator that produces fresh, SymPy-verified problems on demand. Add problems to your [[Vault]] from any topic page.

---

## How Problem Types Work

1. Every topic page lists its problem types in a **"Problems Involving [Topic]"** section.
2. Click **Add to Vault** on a problem type with your chosen difficulty and quantity.
3. The widget picks fresh random problems from a pre-generated bank (tens of thousands of verified problems).
4. Review them in your [[Vault]], print as a worksheet.
